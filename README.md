# Homebrew Jorna

Homebrew tap for [Jorna](https://github.com/imranaskem/jorna), a Postman-like TUI app.

## Installation

```bash
brew tap imranaskem/jorna
brew install jorna
```

## Usage

After installation, run:

```bash
jorna
```

## About Jorna

Jorna is a Postman-like terminal user interface application for testing APIs directly from your command line.

For more information, visit the [main repository](https://github.com/imranaskem/jorna).
